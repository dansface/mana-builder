Privacy Policy

Serverless Architecture

The MTG Manabase Builder is a client-side web application. All calculations and data processing happen directly in your browser—nothing is sent to external servers. Your deck data (mana pips, land slots, and preferences) never leaves your device.

Local Storage

This application uses your browser's local storage to persistently save your work between sessions. Specifically, we store:

  • Deck State: Your mana pip entries, total land slots, and non-basic land selections.
  • User Preferences: Your choice of light or dark theme.

This data remains entirely on your device and under your control. You can clear it at any time by clearing your browser's local storage or clicking the "Reset" button in the calculator.

GitHub Pages Hosting

This site is hosted on GitHub Pages. As with any web hosting, GitHub may collect basic server logs—such as your IP address and browser information—as part of standard web server operations and security monitoring. These logs are governed by GitHub's Privacy Statement and are beyond the control of this application.

No Third Parties

This site uses:

  • ✓ No advertisements
  • ✓ No tracking pixels
  • ✓ No third-party analytics (e.g., Google Analytics)
  • ✓ No external APIs for data collection

The calculator is entirely self-contained and does not integrate with any external services beyond standard GitHub Pages hosting.
